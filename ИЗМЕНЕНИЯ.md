# Что добавлено в программу

## 1. Объединение двух программ
- Менеджер учёта БПЛА и карта-симуляция (IzevskMapProject_v19) стали одной программой `UAV_System`.
- Запуск одной командой: `run.bat` или `python main.py`. Карта и менеджер открываются вместе.
- Кнопка «СИСТЕМА УЧЁТА» на карте снова открывает менеджер, если его закрыли.
- По карте летают дроны из реестра менеджера:
  - зарегистрировал БПЛА — он сразу вылетает;
  - списал — исчезает с карты;
  - отремонтировал — получает новый номерной ID и новый полёт.

## 2. Сессионный ID (вторая защита)
- На каждый полёт выдаётся новый случайный ID вида `S-3F9A1C2B7E4D`.
- Он связан с заводским номером, номерным ID, маршрутом и временем полёта (таблица `sessions`).
- Станция принимает ответ дрона, только если подпись HMAC верна И сессионный ID активен и принадлежит этому дрону.
- Закрытый ID больше никогда не принимается: ни после посадки, ни после перезапуска, ни после списания.
- Новая учебная атака: украден ключ, но подставлен ID прошлого полёта — подмену ловит таблица сессий.
- Вкладка «Полёты» в менеджере: история полётов с поиском.

## 3. Карта
- Подпись дрона на карте и в списке — короткий сессионный ID (`S-…7E4D`), а не заводской номер.
- В обозначениях объяснён серый кружок: «Пропал с радара (нет отметки)».
- Кнопки переименованы: «ДОБАВИТЬ КРАСНЫЙ», «ДОБАВИТЬ ЖЁЛТЫЙ».
- Панель «Информация об объекте»: самое важное (метка, объект, модель, заводской номер,
  номерной ID, сессионный ID, статус, маршрут) выделено светло-голубым.
- Счётчик в правом верхнем углу карты: своих, чужих, опасных, пропавших с радара.

## 4. Менеджер учёта
- Код разбит на маленькие файлы: по файлу на вкладку, логика (`service.py`) отдельно от окон.
- Ремонт теперь проверяет номер новой детали и откатывает изменение при ошибке.
- На вкладке «Списание» виден архив списанных.
- Новая вкладка «Справка»: как работать с программой.

## 5. База данных SQLite
- Все данные учёта перенесены из CSV в один файл `data/uav.db`
  (таблицы `drones`, `deleted_drones`, `sessions`). Старые CSV переносятся автоматически при первом запуске.
- База сама не пускает дубликаты заводского номера и номерного ID (`PRIMARY KEY` / `UNIQUE`).
- Списание (удаление из реестра + запись в архив) — одна транзакция: либо всё, либо ничего.
- Все запросы параметризованы (`?`) — защита от SQL-инъекций.
- В базе изначально 20 БПЛА, из них 16 с моделями российских дронов
  (Орлан-10, Орлан-30, Форпост, Орион, Гранат-4, Элерон-3, Элерон-10, Застава, Тахион,
  Суперкам, Зала-421, Корсар, Альтаир, Птеро, Типчак, Гриф). Модель берётся из заводского номера.

## 6. Карта-подложка
- Программа сама выбирает живой открытый сервер карт (Esri → OpenStreetMap → OpenTopoMap) и распознаёт серверы, которые отдают заглушку вместо карты.
- Исправлен User-Agent запросов карты: старый («TkinterMapView») серверы отклоняли.
- Скрипт `download_map.py` скачивает карту Ижевска и региона до Казани в `data/map_tiles.db`, и карта работает без интернета.
- В правом нижнем углу карты — подпись источника карты.

## 7. Прочее
- Ключ HMAC убран из кода: он берётся из `UAV_SIM_KEY` или из `data/.sim_key` (создаётся случайным при первом запуске).
- Лишние файлы (старые версии, кэш, CSV после переноса в базу) убраны из программы.
- Исправлен `requirements.txt`.
- Чужие объекты без сессии теряют доверие постепенно: сначала жёлтые, потом красные.
